## 建议审阅顺序

1. 总产品地图：确认五款独立 App 的定位。
2. 品牌定位与 UI 设计系统：确认系列统一规范与各 App 差异。
3. 各应用产品 PRD 和 UI/UX 规范：确认全部页面与主工作流。
4. 技术架构和验收矩阵：核对 HarmonyOS API 26 能力、权限与测试要求。
5. 素材需求清单：确认哪些素材值得生成；动态太阳轨迹、时间轴和地图仍须原生绘制。
6. 用户审阅认可后，才开始制作素材与应用图标，并另开 PR 审核。
