## 1. 视觉身份

- 品牌方向：太阳轨迹 + 地平线 + 观测节点。
- 应用专属色：主强调 `#FFBC6B`、辅助 `#73D9D5`。
- 共用暗色：`#0B1622` 背景、`#152836` 面板、`#1C3546` 控件/悬浮层；文字 `#F9FAF3` / `#93A9B6`。
- 浅色：暖纸底 `#F4F1EA`、白色卡片、深色文字，主色应按可读性重新标定，不能直接把亮色当小号字体。
- 图标设计：太阳轨迹 + 地平线 + 观测节点；无文字、矢量可复刻、与 Xuzuo 统一线宽/圆角/内留白。
- 字级：显示 34vp、H1 28vp、页面标题 20vp、正文 14–16vp、辅助 11–12vp，重要数值等宽。
- 动效：120–240ms 轻量转场，支持减少动态效果。

## 3. 共用路由与界面状态

- 导航结构：一层仅展示高频入口，子功能使用 NavDestination；退出未保存表单显示二次确认。
- 状态机：`EMPTY → LOADING → READY`；异常进入 `NO_PERMISSION / UNSUPPORTED / RECOVERABLE_ERROR / FATAL_ERROR`，每个状态都能回到有效路径。
- 反馈：成功显示具体对象/文件/结果，不只弹“成功”；系统 Picker 取消不显示成功；任务失败附错误码与重试。
- 输入校验：整数/浮点、长度、非法文件、重复名称、日期/时区等专用校验在保存前运行。
- 长页：展开/折叠次要信息，主操作固定在舒适区域，避免“满屏卡片”的模板化设计。

## 4. 当前应用专属布局和动线

- 首屏就显示业务事实：顶部机位/日期/UTC 偏移（紧凑 1–2 行）→ 方位/高度仪表 → 太阳真实曲线 → 夜间/蓝调/黄金/白昼分段带 → 下一时段 → CTA。不要大型营销图片挡住读数。
- 与 `design/ui1b-r2/final-home.html` 的 360/390/430 方案对齐；宽 600–899 单列，900+ 双栏，1200+ 侧导航+检查器。原型并非已落地 ArkTS。
- 曲线坐标轴显示高度刻度与地平线；同一 `selectedUtc` 驱动标记、阶段、偏移和读数；23/25 小时按真实日宽度。
- 每一个阶段只出现一次关键说明，避免日出日落、阶段词在多个卡片重复。
- 引导插画只在首次引导、空状态使用，不要放在首页关键计算区域。

## 5. UI 基础交付与源码映射

- `ThemeTokens` 使用共享语义 Token，再覆盖当前 App 两种强调色。
- 每页提供导航进入/返回、加载/空/错/正常、权限拒绝与大字体至少一种截图。
- ArkUI `Navigation`/`NavDestination` + 原生 Canvas/图像层，不使用 HTML WebView 包装设计稿作为最终应用。
- 所有设计图、图标源稿和生成插画都归本资源仓库管理，正式 HAP 仅复制经过批准、压缩的输出。
