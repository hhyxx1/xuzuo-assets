# 应用专项指令：声剪 VoxCarve

**预期身份**：VoxCarve / 声剪；拟定 bundle **com.hhyxx.voxcarve**（AGC 注册前候选）。2026-11-12 未找到同名公开仓库，进入工作区前重新检查用户本机已有工程与授权的 GitHub 访问范围。

## 产品定位

一个**文字联动的真实音频剪辑工具**：音/视频文件导入、音频轨解析、波形/片段选择、可复核文本与时间戳、非破坏性剪辑、试听、字幕、导出。默认本地优先，联网转写若需要必须有明确的媒体上传许可和供应商信息。

采用紫藤 #AF9DFF + 杏色 #FDBF92 辅色，四款共用中性基底，避免发光紫色波形海报。专业编辑器优先清晰时间码、操作和波形可用性。

## 全部 10 页

projects 项目首页；import 音视频导入；transcript 文字稿；timeline 音频剪辑台；silence 停顿复核；captions 字幕；preview 剪后试听试看；export 导出；history 历史与版本；settings 设置。

## 分阶段任务

1. **01 官方/API 探测**：File Picker URI 生命周期、媒体拆封装/解码/PCM、AudioRenderer/AudioEncoder/AVMuxer、音视频时码语义、Core Speech Kit 语言/模型可用性/返回的时间戳粒度（若有）、网络/数据传输限制。必须查本机 SDK26 声明与官方参考，不随意写导入路径。
2. **02 架构与组件**：MediaProject / SourceTrack / TranscriptSegment / EditDecision / RenderSequence / CaptionCue / RenderTask；强调 source start/end 单位、sampleRate、monotonic PTS 和可逆的 edit graph。共用导航/按钮/表单，专有波形与文本编辑独立组件。
3. **03 真音频闭环**：用户选一个真实授权音频→复制/引用合法 URI→解析时长/声道→真正解码生成可绘制波形→播放试听→拖动/输入精确时间区间→保存非破坏性编辑决定→渲染为真实 WAV→外部播放器验证剪切时长和内容。转写暂不可用时不能阻挡无 ASR 剪辑流程。
4. **04 全部页面**：Project 列表、音频导入、文字稿人工编辑与说话人标记、逐句时间码、波形剪辑、片段复核、字幕编辑、历史撤销/重做、导出设置。每个按钮真实关联数据，不可把假定的文字稿和波形当作处理结果。
5. **05 扩展**：按官方/设备支持追加字幕 SRT/VTT 严格时间排序、MP3/MP4 编码或安全降级、可取消任务、静音候选算法、可解释的词/句级对齐和人工校准。如果 Speech Kit 没有可靠的词级时码，产品不得宣称精确逐字剪辑。网络识别不默认上传用户音频。
6. **06 QA**：短/长音轨、不同采样率、立体声、损坏媒体、边界裁切、时间轴单位转换、音画同步、VTT/SRT 编码/重叠、重启恢复、原始音频未损坏、取消后无错误成功状态。

## 禁止

没有真实 ASR 就填入编造逐字稿；把文字直接删除却不裁剪音频；将音频导出成空文件或改名 WAV；无用户许可上传音频到云端；写死“98%准确率”；在 HTML CSS 画固定假波形到生产编辑器。

## 独立验收

至少保存两套可复现的音频样本、实际导出文件的时长/波形/哈希与外部播放器结果（仅测试素材）；所有性能/精度数字必须来自实际测试。联网语音功能仅在权限、费用和政策明确时启用。
