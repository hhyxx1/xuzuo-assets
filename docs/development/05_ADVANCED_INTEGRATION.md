# 阶段 05 · 复杂设备能力、导出、边界条件与集成

## 发给 AI

继续当前 App 的阶段 05。阅读 APPS/<slug>.md、03_TECH_SPEC.md 和 04_ACCEPTANCE.md。用真实 SDK26 官方文档与本机声明实现本项目全部高风险剩余需求，不得把设备不支持的功能凭空补成“按钮可点”。本阶段的目标是**可核验的复杂业务子系统**，不是特效。

一、API 证据与能力探测
1. 每引入一个 SDK/Kit/API，从华为 developer.huawei.com 官方具体 API Reference、相关指南、设备 API26 的本机声明和权限/ACL/SystemCapability 判定可行性。先写独立 probe，实际构建并在有条件的设备运行，收集真实返回/错误码。若只能在宿主测试，标注验证层级。
2. 编码器/解码器/相机分辨率、传感器、Speech、地图、网络、AGC 服务不是“文档存在就可以依赖”；实现 feature detection 与降级路线，受限能力让用户明确知道设备/权限/服务条件。
3. 所有异步长任务采用可恢复状态机：NEW → VALIDATING → RUNNING → VERIFYING → SUCCESS / FAILED / CANCELLED / UNSUPPORTED。取消要释放资源，不允许部分文件误报成功；错误应带可复现码和重试策略。

二、各应用高风险工作
- **LightBearing**：DST 回拨/前跳、非24小时日、IANA 时区、极昼极夜、曙暮光、1969负时间戳、跨日期线；时间轴必须使用真实 UTC 区间不是画死24小时。反向寻光角度环形误差、短窗口漏报、跨日最优、maxResults 分布；图表展示与业务数据一致。真实 CSV/PNG 输出并用外部工具独立验收。
- **FrameMori**：Camera Kit 预览与拍照能力/多机型 AF/AE/AWB、洋葱皮叠加性能、缩略图/元帧索引、Frame duration、视频编码/封装 PTS 单调性、帧率与音轨同步、外部播放器逐帧核验。不同格式只有经官方 API 和真机 probe 支持后才提供。
- **VoxCarve**：音视频解码/PCM 波形、可逆非破坏性编辑图、起止时间映射与样本边界、SRT/VTT 时间码、真媒体导出、ASR 语言/网络/离线/权限/词级或句级时间戳粒度与人工对齐。绝对不伪造转写准确率或空凭空生成词级对齐；无可用 Speech 时仍可手动编辑音频/字幕。
- **MacroLoom**：Windows Agent 与 HarmonyOS 原生客户端完整双端，TLS/WSS 证书指纹/可撤销配对/一次性验证码/重放保护/执行签名/设备白名单/超时/速率限制/确认；仅执行本地用户认可的白名单动作，不接受手机端任意 shell/PowerShell 命令，不绕过 Windows UAC/锁屏；离线重连必须防重复执行，报告真实回执。
4. 按专项文档覆盖其他尚未完成功能，PRD 列表不得悄悄删除；不可行时列出明确 blocked 的功能 ID、SDK/设备/许可证证据、用户界面可用的安全替代行为。
5. 验证隐私：敏感媒体/位置/配对材料在本地存储，用户授权与撤销流程真实有效；不保留签名、密码、私有 token 于仓库、日志、截图。测试素材专用、可清理。
6. 形成 INTEGRATION_REPORT.md：功能 ID、调用 Kit、probe/真机、成功证据/文件哈希/播放器/Windows Agent 日志、错误码、恢复路径。更新 API_AUDIT 与测试表。
7. 每次子系统改动运行相关 build/test，失败修复再继续；设备不可接入时做到宿主可验证的尽可能多的真实逻辑，而不要宣称整个 App 完成。

**完成定义**：高风险子系统要么真正实现并有测试，要么有具体可复验阻碍和 UI 降级；所有用户承诺都有可观察证据；媒体与控制执行通过独立通道核验。
