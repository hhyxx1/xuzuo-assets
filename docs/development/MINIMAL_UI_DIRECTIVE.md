# 四款 App 简约工具视觉裁定（覆盖旧预览的重渐变）

**用户最新正式视觉决策**：四款统一的基础视觉系统，但各自有专业的工作区。风格必须极简、实用、可读、少装饰、少渐变；不像 AI 生成的仪表盘海报。StoroPix 已发布且设计独立，不参与。

## 共用主题与 App 强调色

| 应用 | 主色 | 小面积辅助色 |
|---|---|---|
| LightBearing | #FFBC6B 琥珀 | #73D9D5 青 |
| FrameMori | #FF9471 珊瑚 | #75DDC4 薄荷 |
| VoxCarve | #AF9DFF 紫藤 | #FDBF92 杏 |
| MacroLoom | #B3F07C 青柠 | #7FC8FF 天蓝 |

中性深色：背景 #0B1622、表面 #152836、浮层 #1C3546、正文 #F9FAF3、次要 #93A9B6。浅色主题应测对比度后再定最终可读 token，不允许把浅黄/青直接用作浅底小字号文字。

## 必须做

- 首页突出用户核心任务，导航保持 3–5 个主入口并按工作流确定；页面层级、返回与确认/取消始终清晰。
- 共用抽象：AppBar、BottomNavigation、SegmentedTabs、Button、IconButton、FormField、ListRow、StatusChip、Dialog、BottomSheet、PermissionState、TaskProgress、EmptyState、ErrorState。
- 主要容器**纯色背景**；卡片仅在有清晰分组价值时使用；1px 细分割线；小范围少量强调色；字体与间距比阴影更重要。
- 同屏最突出的主 CTA 通常只有一个；辅助操作更弱。点击目标 ≥48vp；屏幕安全区/屏幕阅读器/放大字体/错误提示与减少动效全面支持。
- 支持 360/390/430vp 以及 ≥600vp，优先手机真实可用而非概念海报。
- 图表必须用真实数据：逐光日轨由计算内核驱动，帧间时间轴由真实帧驱动，声剪波形与时间码由媒体驱动，键阵状态由 Windows Agent 回执驱动。
- AI 生图只用于正式图标候选、少量引导和空状态插画。没有素材时用纯色+简单图形占位，不要因为没图就停工。

## 不能做

- 不要大面积渐变、毛玻璃、泛光描边、霓虹线、背景浮动装饰、花哨 3D、重复大 Banner 或每页重复“四色卡片”。
- 不要把底部导航栏、按钮、输入框、图表、波形、机位地图画成静态图片。
- **尤其 LightBearing**：旧生产 UI 与 R2 HTML 用户不满意，新的 ArkUI 必须按任务逻辑重新排版，不沿用视觉；只保留算法、领域与可靠性资产。
- HTML 设计稿仅用来盘点页面/组件/流程；其 CSS 里出现的渐变不是新正式样式要求。
