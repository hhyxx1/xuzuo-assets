# 素材制作计划与入库规范（审核前不生成）

> **文档版本：v0.3｜状态：DRAFT_FOR_REVIEW｜草案日期：2026-11-12**。本规范尚待用户批准，不代表已发布或真机验收。

## 本轮状态

`PLANNED_ONLY`：以下只是文件命名、风格和验收合同。任何生图、图片编辑、压缩、上架成品制作都需用户先通过本次文档审核。

## 未来素材目录建议

```text
assets/
  brand/{identity,icons,templates}/
  apps/<slug>/
    source/           # 已批准的原始生成图/可编辑来源
    export/           # 已压缩/裁剪的 App 资源，带尺寸和格式
    onboarding/       # 引导图与空状态
    share/            # 分享卡背景（真实数据文字由代码渲染）
    store/            # 应用市场展示图、截图模板
  manifests/          # 素材元数据清单、许可证、SHA256、版本
```

## 命名约定

`<slug>__<scene>__<variant>__<w>x<h>__vNN.webp`，例：`lightbearing__onboarding-01__dark__1080x1920__v01.webp`。源图可以是 PNG，但运行时优先评估 WebP/AVIF 是否得到 SDK 支持，再选择兼容格式。

## 入库前校验

- 每张图明确用途、真实输出宽高、色域、Alpha、裁剪安全区和目标系统版本。
- 生成与导出分离；所有图片必须有人工检查：透视、手指、相机与三脚架结构、太阳方向、重复线条、无文字水印。
- 打包资源按用途预算大小；无损只用于需要透明度和精细图标边缘的资源。
- 严格分开“概念示意”和“真实轨迹”。绝对不让生成图片承担太阳位置、经纬度、真实拍摄时间等计算事实。
- 原创素材不得复制第三方品牌/受版权保护角色；跨来源许可评估通过后再入库。
- 统一记录 `ASSETS_MANIFEST.csv` 或 JSON：文件、来源、prompt 版本、生成日期、人工审核人、用途、许可证、SHA256、压缩版尺寸。

## 已讨论的 LightBearing 素材（尚未加入此仓库）

- `app-icon`：精简几何太阳轨迹图标（先验证启动器尺寸效果）。
- `onboarding-01/02/03`：日光发现、方向规划、拍摄计划；作为可跳过引导的配图。
- `empty-locations`：无收藏机位时的小幅信标插画。
- `share-golden-hour`：分享卡背景；需去掉虚构的太阳轨迹辅助线，由代码添加精确数据。
- 不在 LightBearing 首页插入满屏风景图；首页第一屏必须先展示真实太阳读数与操作。
