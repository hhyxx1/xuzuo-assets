# 隐私、安全与发布边界

## 默认政策

- 本地优先，无强制注册；未经用户操作不联网上传原视频、录音、照片、机位坐标和电脑配对信息。
- 以系统选择器选择文件；每次访问目的可解释，删除项目时清理相关沙箱副本。
- 应用内提供数据删除、缓存清理与导出选项，并区分“缓存”和“原始资产”。
- 不在 Git 仓库存储真实用户手机号、位置历史、账号、API Token、签名密钥、平台私有证书、原声录音。
- 日志仅存问题诊断所需的字段：错误码、能力探测结果、时间耗时、任务 ID；定位只保留必要的模糊化信息或不记录。

## 每产品风险

**LightBearing**：机位位置属于敏感使用场景，不上传机位；分享前让用户明确选择是否公开精确经纬度。定位只前台一次。

**FrameMori**：相机/麦克风隐私；不要在后台偷偷拍摄；临时帧与最终素材清理需让用户确认。

**VoxCarve**：录音/人声可能含个人信息或受版权保护；默认本地识别优先，在线转写若加入需明确说明服务商、发送内容、时长、费用与删除政策。不得默默上传。

**MacroLoom**：WSS、配对指纹验证、设备白名单、授权撤销、速率限制、动作白名单、紧急停控。绝不执行手机端传入的任意 shell/PowerShell；不得越过 Windows UAC、锁屏和安全桌面。

**StoroPix**：商品照片可能包含客户地址、标签、订单信息；导出可选择去除 EXIF 敏感元数据；默认不上传原图做云端 AI。

## 开源/商业和素材版权

- “公开 GitHub 仓库”不等于“所有素材可任意商用/二次分发”；许可证必须单独明确。
- AI 生成图、第三方素材、字体、图标、截图需各自建立来源与使用权限清单。
- 第三方图标/字体遵守授权与 NOTICE，不上传授权不明确的字体文件。
- 公共品牌资产可与应用源码使用不同许可证；本阶段不擅自决定许可证。

## 版本发布门槛

每次上架前完成隐私政策、权限解释、第三方 SDK 清单、商品宣传真实性、故障回退、安全测试和打包体积评估。无法确认的系统 API/服务一律视为待验证。
