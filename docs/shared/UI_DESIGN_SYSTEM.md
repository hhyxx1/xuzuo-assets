# Xuzuo UI · ArkUI 设计规范 v0.3

## 布局与密度

- 基础空间单位 4vp；常用间距 4/8/12/16/20/24/32vp。
- 手机宽 360–430vp 重点验收：内容单栏；主操作不隐藏在屏幕底部；导航栏尊重安全区。
- 600–899vp：使用加宽单列或轻量双栏，依据实际内容区域宽度判断，不盲目依据屏幕总宽。
- 900–1199vp：工具主体 + 侧检查器；≥1200vp 才考虑左导航 + 主工作区 + 右检查器。
- 不强制五款所有页面都三栏。摄影图表、时间轴、相机预览、批量图片网格各自有专属最佳布局。

## 主题 Token

| Token | Dark | Light | 语义 |
| --- | --- | --- | --- |
| `background` | `#0B1622` | `#F4F1EA` | 页面底色 |
| `surface` | `#152836` | `#FFFFFF` | 主卡片 |
| `surfaceElevated` | `#1C3546` | `#E7EDEB` | 浮层/控件底色 |
| `textPrimary` | `#F9FAF3` | `#141F2A` | 主要文字 |
| `textSecondary` | `#93A9B6` | `#52636D` | 次要文字 |
| `outline` | `#3D5360` | `#CCD8D6` | 分割线 |
| `danger` | `#F27573` | `#B83C39` | 危险操作 |
| `success` | `#76D1A2` | `#167C4F` | 成功结果 |

LightBearing 深色主色用琥珀 `#FFBC6B`；浅色避免直接复用亮琥珀作为小字，改用较深的 `#9A5A0C`。其他 App 也应对浅色主题逐一测对比度。

## 文字层级

- Display：32–36vp，使用等宽数字（经 UI API 核验）；适用仪表读数。
- H1：26–30vp；H2：19–22vp；Section：16–18vp；Body：14–16vp；Caption：11–12vp。
- 重要数字与解释标签保持物理关联，不用颜色独自表达状态。
- 较长中文/英文名称采用限制行数与尾部省略，不挡住其他控件。

## 统一组件和变体

| 组件 | 必须支持的状态 | 设计细节 |
| --- | --- | --- |
| `PrimaryButton` | normal/pressed/disabled/loading | 最小热区 48vp；危险动作不使用主色误导 |
| `SecondaryButton` | normal/pressed/disabled | 边框清晰；文字可读 |
| `StatusChip` | neutral/success/warning/error | 附带形状/文字，不只用色 |
| `ToolBar` | 横/竖屏/窄屏溢出 | 对应高频编辑动作，图标有 label |
| `EmptyState` | 首次/无匹配/不支持 | 小幅插画、原因、唯一明确 CTA |
| `PermissionGate` | 未申请/拒绝/系统关闭/可用 | 解释用途与手动降级，不频繁重复弹窗 |
| `ProgressSheet` | 排队/执行/取消/失败/完成 | 显示具体任务、进度、可取消路径 |
| `ProjectTile` | 正常/选中/损坏/归档 | 实际元数据摘要、长按菜单 |
| `ConfirmSheet` | 保存/丢弃/永久删除 | 详细对象名及不可逆说明 |
| `AdaptiveNav` | 手机底栏/平板侧栏 | 一级入口不堆满，二级用 Navigation |

## 输入、反馈与动效

- 点击反馈 <180ms、列表载入有骨架屏、危险删除可撤销或二次确认。
- 120–240ms 平滑过渡，避免一级 Tab 切换双段动画。
- 对录制、媒体渲染、网络控制等异步任务，进度、实际状态与停止操作必须一致。
- 为“减少动态效果”提供应用内开关；不要声称已读取系统减少动效开关，除非 SDK26 验证支持。

## 无障碍与国际化

- 触控热区目标 ≥48vp（至少 44vp），SVG/按钮提供 accessibilityText。
- 颜色对比度以 WCAG AA 为设计参考，不声称这就是鸿蒙上架强制指标。
- 单位、时区、日期、经纬度、帧率、音频时间码等统一格式化模块；重复本地时刻标明 UTC 偏移。
- 简体中文为主，英文展示文本可在后续提供，禁止将界面文字硬编码到图片中。

## 不能跨 App 机械共用的界面

- LightBearing 的日轨、方位/高度、时段带：Canvas + 实时计算。
- FrameMori 的相机预览、洋葱皮、帧时间轴：专属性能组件。
- VoxCarve 的音频波形、时间区间拖动：专属编辑器。
- MacroLoom 的按钮网格、按下反馈：操作可靠性优先。
- StoroPix 的批量图片网格与修图工作台：原图与产出对照优先。
