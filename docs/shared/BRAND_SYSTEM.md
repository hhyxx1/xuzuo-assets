# 序作 Studio · 品牌系统 v0.3

> 「序作 Studio / Xuzuo Studio」是提议名称，未做充分的商标与重名核验；勿直接写成已获得排他权的商标。

## 品牌人格

- 关键词：精确、克制、温暖、有创造力、可信赖。
- 产品承诺：把复杂工作中最重要的一件事做好，让人愿意每天打开。
- 避免：泛 AI 闪光效果、夸张“100% 自动”、过度拟物、广告化欢迎页、无限滚动卡片堆砌。
- 中文口吻：短句、动作导向、提示下一步；明确精度与限制。
- 英文口吻：简洁、自然，不堆砌 AI/Premium/Pro 字眼。

## 图标与插画准则

- App Launcher：统一圆角方形内部视觉、安全留白和单一主形状；不要把真实系统圆角重复写死在成品资源里。
- 图标以正交/45°/圆弧等基本几何建立统一性；深色底为基准，但在浅色墙纸上也要清晰。
- 功能性小图标：用一致的线宽和光学尺寸绘制 SVG；禁止使用随平台变化的 emoji 当作正式图标。
- 插画：用在首次引导、空状态、分享宣传，少量高质量。不在编辑时间轴、测量罗盘、方位图里用静态生成图替代真实数据。
- AI 生成的轨迹、太阳方位示意、时间数字不应当成为真实结果；由代码动态叠加。

## 命名/标语

- Studio 总标语（候选）：让灵感有序发生。 / 为每一份创作，准备好工具。
- LightBearing：好光线，值得提前抵达。
- FrameMori：让每一帧，都有生命。
- VoxCarve：从文字，剪出好声音。
- MacroLoom：一个按钮，串起工作流。
- StoroPix：一批出好图，一店好风格。

开发者主页可以展示系列，但每款 App 仍有独立应用名、介绍、图标和隐私说明。应用内“更多作品”只能在不打扰核心工作流的位置出现，并明确属于同一开发者。上架前各自做名称和商标检索，不冒充注册商标。
