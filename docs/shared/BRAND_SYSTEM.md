# 序作 Studio · 品牌系统 v0.3

> 「序作 Studio / Xuzuo Studio」是提议名称，未做充分的商标与重名核验；勿直接写成已获得排他权的商标。

## 品牌人格

- 关键词：精确、克制、温暖、有创造力、可信赖。
- 产品承诺：把复杂工作中最重要的一件事做好，让人愿意每天打开。
- 避免：泛 AI 闪光效果、夸张“100% 自动”、过度拟物、广告化欢迎页、无限滚动卡片堆砌。
- 中文口吻：短句、动作导向、提示下一步；明确精度与限制。
- 英文口吻：简洁、自然，不堆砌 AI/Premium/Pro 字眼。

## 品牌适用范围（2026-11-12 用户决策）

**核心同风格四款**：LightBearing（逐光）、FrameMori（帧间）、VoxCarve（声剪）、MacroLoom（键阵）。这四款共享图标几何原则、色彩与主题 token、插画叙事方式、组件规范和动效约束；各自保留专业工作台与强调色。

**独立风格例外**：StoroPix（店图匠）已发布并完成自己的视觉定型，不纳入上述四款的强制统一视觉。继续保留其现有 App 图标、主题、色彩、导航、页面结构和商店展示；没有另行审批，不为了“序作系列统一”而换图标、改页面或增加系列品牌标识。仍可共享 API 26 工程、安全、文档索引、素材归档和测试规范。

**重要**：`xuzuo-assets` 可收纳五款产品的资料，不代表五款都属于同一视觉设计系统；系列品牌与四款视觉体系仍是待正式批准的草案，而 StoroPix 视觉独立是明确决定。

## 图标与插画准则

> 以下**统一几何与插画风格规则只对上述四款生效**；StoroPix 可参考无障碍和素材真实性要求，但不接受视觉强制迁移。

- App Launcher：统一圆角方形内部视觉、安全留白和单一主形状；不要把真实系统圆角重复写死在成品资源里。
- 图标以正交/45°/圆弧等基本几何建立统一性；深色底为基准，但在浅色墙纸上也要清晰。
- 功能性小图标：用一致的线宽和光学尺寸绘制 SVG；禁止使用随平台变化的 emoji 当作正式图标。
- 插画：用在首次引导、空状态、分享宣传，少量高质量。不在编辑时间轴、测量罗盘、方位图里用静态生成图替代真实数据。
- AI 生成的轨迹、太阳方位示意、时间数字不应当成为真实结果；由代码动态叠加。

## 品牌结构与对外展示

开发者主页可以展示五款相关作品，但只把前四款描述为同风格视觉系列；StoroPix 属于独立品牌作品。每款 App 仍有独立应用名、介绍、图标和隐私说明。应用内“更多作品”只能在不打扰核心工作流的位置出现，并明确属于同一开发者。上架前各自做名称和商标检索，不冒充注册商标。
