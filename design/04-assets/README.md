# 04 · 正式素材源文件

本目录提供**独立可编辑 SVG**；不允许从 01 的海报直接裁切按钮、把静态 UI 图当作原生可交互组件。

- `app-icons/<app>.svg`：四款 App 视觉一致、图标语义不同；可作为绘图源文件，最终 HAP 适配/PNG 导出另行验证。
- `onboarding/<app>-welcome.svg`：可用于引导页的抽象背景插画，没有功能性文字。
- `empty-states/<app>-empty.svg`：统一线条与色板的空状态图，不内嵌 CTA 文案。
- `share/<app>-share-bg.svg`：分享卡背景，不内嵌假的太阳方位/进度/设备状态数据。
- `manifests/assets.json`：所有素材路径、用途、生成方法、许可证/审稿状态、导出注意事项。

**许可**：SVG 由本轮程序化原创绘制，第三方字体/照片未包含；具体项目发布许可尚未决定，不能默认所有第三方获准商用。
