## 程序开发接入说明
1. 从 `assets.json` 选择素材；核对来源/许可状态和实际 viewBox。图标主色从共享 Token 读取。
2. 源图（SVG）→ **按系统 SDK26 / 设备图形管线实际支持情况**导出 PNG/WebP 或其他兼容格式；避免直接认定 HarmonyOS 所有 Image 能完全支持 SVG 滤镜/文本。
3. 按不同设备的尺寸和像素密度生成 PNG/WebP；在真机检查透明边缘、文字（这些素材没有嵌入）、色域与性能。
4. 使用固定文件名和版本号将选中资源复制到业务源码仓库的资源目录；不要在运行时访问本 GitHub 仓库作为素材 CDN。
5. 分享卡背景只提供情绪氛围；光线角度、时刻、字幕内容、宏执行记录等**必须由真实应用数据在 ArkUI 中叠加**。
6. 资源未获最终版本审图与授权许可确认前保持 `DESIGN_DRAFT`，不能推断是商店上线成品。

StoroPix 仅在本仓库共存原有相关文档，**没有加入四款统一视觉素材制作**。

### 数量与尺寸
本轮登记 **94 个独立 SVG 资源**（另有 5 个概念 SVG、42 个页面设计 SVG），具体以清单为准。独立图标 1024×1024，线性图标 24×24，引导 960×600，空态 480×320，分享背景 1080×1350。

`gitBlobSha` 是 Git 对文件内容的 SHA-1 对象标识，不是用来替代 SHA-256 的版权校验；本地 `node design/tools/check-kit.mjs` 还能输出 SHA-256。
