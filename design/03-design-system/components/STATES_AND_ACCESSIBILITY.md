# 通用组件交互状态与无障碍验收
| 状态 | 必须明确呈现 | 交互要求 |
| --- | --- | --- |
| empty / first-use | 解释缺什么 + 创建/导入 CTA | 无“空白页面” |
| loading | 骨架或真实进度，不重复提交 | 可取消的任务允许取消 |
| ready | 核心数据、更新时间、操作按钮 | 可由读屏区分 |
| error | 人类可读错误 + 技术错误码(可展开) + 重试 | 重试幂等 |
| permission-denied | 权限理由 + 系统设置路径或替代操作 | 不循环弹窗 |
| unsupported | 机型/Kit 不支持的说明 | 功能禁用，不假功能 |
| offline / interrupted | 本地编辑可用性、未保存变更 | 恢复后可继续 |
| success | 外部可验证结果（URI/ACK/校验） | 不用单一 Toast 证明成功 |

- 所有点击热区建议至少 48vp；文字对比度参照 WCAG AA，但不是宣称 HarmonyOS 强制指标。
- 图标按钮必须带标签；数值和状态不能仅依靠颜色区分。
- 长文本、横屏、放大字号、折叠/大屏、中文英文切换都不能遮挡主要操作。
- 隐私：预览截图不要使用真实用户图片、token、设备 ID、真实位置信息；示例统一标注虚构。
