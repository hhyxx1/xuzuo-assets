# DESIGN QA · 交付判定
> 本页定义“设计文件”验收；**不等于 SDK API 可用或生产功能已实现**。

- [ ] 4 款 App × 各 12/10/10/10 页，合计 42 份独立 SVG 页面文件全部存在（每页 390×844 示例画布）。
- [ ] 每个业务页面存在同名独立规格 MD，描述目标、组件、操作、数据、异常和跳转。
- [ ] 交互式 HTML 页面画廊能够在浏览器离线打开，切换 app/page 并预览独立 SVG；无网络 CDN 依赖。
- [ ] 统一 Token 只有一个事实源；四款差异通过 Accent 变体，不复制四份组件 CSS。
- [ ] 正式素材含 SVG 独立图标、引导插画、空态、分享背景和清单，**不是从设计大图截图裁剪的按钮**。
- [ ] LightBearing 新设计独立构思；不调用旧 UI/R2 HTML 的布局或 CSS，不把概念太阳曲线当计算结果。
- [ ] StoroPix 不发生任何视觉变更。
- [ ] 素材都有用途、尺寸/viewBox、格式、版权来源和审核状态；无法确认的许可标记未核。
- [ ] 导出 PNG/WebP 若需要，需 SDK 26 与图形管线实际转换后再入 HAP；SVG 源图本身不是已部署文件。
- [ ] 未运行的 UI 自动化/真机测试必须显示 `NOT_RUN`，不声明“production ready”。

**预期后续流程**：用户审图 → 修改/批准 SVG & 组件 → 编程 AI 复用设计 token 实现 ArkUI → 真机校验 → 生成上线导出资源（需进一步批准）。
