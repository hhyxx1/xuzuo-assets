# 键阵 MacroLoom · 安全与设置

> **页面 10 / 10** · `macroloom/settings` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

连接加密、权限、面板、通知和备份。

**页面副标题：**控制越方便，边界越清楚

## 内容结构（由上至下）

1. **安全设置** — `settings`。
   - 可见元素：连接权限、执行确认、本机生物认证、自动断线
   - UI 演示值（不是设备数据）：仅已配对 / 危险操作需确认 / 可选 / 开启
   - 对应 ArkUI：SettingRow → ListItem / Toggle
2. **界面偏好** — `settings`。
   - 可见元素：布局、主题、通知、备份
   - UI 演示值（不是设备数据）：3×3 / 深色 / 开启 / 仅手动
   - 对应 ArkUI：SettingRow → ListItem / Toggle
3. **隐私声明** — `list`。
   - 可见元素：配对密钥仅本机保存、日志不可记录凭据、不会绕过 UAC 和锁屏
   - 对应 ArkUI：ListRow → List / LazyForEach

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#B3F07C`、辅助色 `#7FC8FF`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
