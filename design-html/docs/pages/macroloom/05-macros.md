# 键阵 MacroLoom · 宏编辑器

> **页面 05 / 10** · `macroloom/macros` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

逐步骤设置执行、延时、条件与失败处理。

**页面副标题：**把重复步骤编成一次动作

## 内容结构（由上至下）

1. **宏属性** — `form`。
   - 可见元素：宏名称、执行模式、失败处理
   - UI 演示值（不是设备数据）：构建并启动 / 串行 / 立即停止
   - 对应 ArkUI：FormField → TextInput / DatePicker / Menu
2. **宏步骤** — `checklist`。
   - 可见元素：运行构建命令、等待 3 秒、启动指定应用、通知执行结果
   - 对应 ArkUI：ChecklistRow → Checkbox / persisted state
3. **安全边界** — `list`。
   - 可见元素：不可绕过 UAC、不可绕过锁屏、不执行未授权命令
   - 对应 ArkUI：ListRow → List / LazyForEach
4. **步骤操作** — `grid`。
   - 可见元素：新增、删除、上移、下移
   - 对应 ArkUI：ActionGrid → Grid / GridItem

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#B3F07C`、辅助色 `#7FC8FF`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
