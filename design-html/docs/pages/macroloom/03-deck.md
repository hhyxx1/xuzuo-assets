# 键阵 MacroLoom · 控制面板

> **页面 03 / 10** · `macroloom/deck` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

可自定义按钮网格、状态回执、失败重试。

**页面副标题：**高频动作，触手可及

## 内容结构（由上至下）

1. **面板组** — `tabs`。
   - 可见元素：默认、开发、媒体
   - 对应 ArkUI：SegmentedTabs → Tabs / custom component
2. **默认面板** — `deck`。
   - 可见元素：构建、清理、IDE、截图、锁定、音量+、上一首、播放、下一首
   - 对应 ArkUI：ControlDeck → Grid + CommandStatus
3. **执行状态** — `metrics`。
   - 可见元素：执行中、已完成、失败、待确认
   - UI 演示值（不是设备数据）：0 / 4 / 0 / 1
   - 对应 ArkUI：MetricCard → Grid + Text + status
4. **操作约束** — `list`。
   - 可见元素：危险命令必须二次确认、所有执行结果带回执、脱机时禁用远程按钮
   - 对应 ArkUI：ListRow → List / LazyForEach

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#B3F07C`、辅助色 `#7FC8FF`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
