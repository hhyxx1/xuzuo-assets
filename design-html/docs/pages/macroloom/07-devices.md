# 键阵 MacroLoom · 设备列表

> **页面 07 / 10** · `macroloom/devices` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

展示在线设备、密钥状态、最近连接与撤销。

**页面副标题：**知道谁有权限连接你的电脑

## 内容结构（由上至下）

1. **已配对设备** — `list`。
   - 可见元素：工作电脑 · 在线、家用电脑 · 离线、测试机 · 等待授权
   - UI 演示值（不是设备数据）：12 ms / 上次昨天 / 未连接
   - 对应 ArkUI：ListRow → List / LazyForEach
2. **连接概览** — `metrics`。
   - 可见元素：在线、离线、待审核、过期授权
   - UI 演示值（不是设备数据）：1 / 1 / 1 / 0
   - 对应 ArkUI：MetricCard → Grid + Text + status
3. **设备属性** — `form`。
   - 可见元素：显示名称、服务端地址
   - UI 演示值（不是设备数据）：工作电脑 / 局域网
   - 对应 ArkUI：FormField → TextInput / DatePicker / Menu
4. **设备操作** — `grid`。
   - 可见元素：重新连接、断开、查看详情、撤销
   - 对应 ArkUI：ActionGrid → Grid / GridItem

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#B3F07C`、辅助色 `#7FC8FF`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
