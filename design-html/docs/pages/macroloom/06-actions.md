# 键阵 MacroLoom · 安全动作库

> **页面 06 / 10** · `macroloom/actions` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

预置常用动作与受限高风险动作分组。

**页面副标题：**可控的操作，才值得一键执行

## 内容结构（由上至下）

1. **动作类别** — `tabs`。
   - 可见元素：应用、媒体、系统
   - 对应 ArkUI：SegmentedTabs → Tabs / custom component
2. **动作模板** — `grid`。
   - 可见元素：启动应用、媒体播放、音量调节、窗口切换、屏幕截图、通知
   - 对应 ArkUI：ActionGrid → Grid / GridItem
3. **权限需求** — `list`。
   - 可见元素：普通执行：单击确认、文件修改：明确路径与范围、系统级动作：额外确认
   - 对应 ArkUI：ListRow → List / LazyForEach
4. **安全规则** — `checklist`。
   - 可见元素：禁止任意远程 shell 默认开放、动作可查看参数、运行日志记录敏感字段最小化
   - 对应 ArkUI：ChecklistRow → Checkbox / persisted state

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#B3F07C`、辅助色 `#7FC8FF`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
