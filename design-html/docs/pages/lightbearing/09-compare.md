# 逐光 LightBearing · 时间比较

> **页面 09 / 12** · `lightbearing/compare` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

对比两日期或两个时段的太阳高度、时窗与最佳拍摄角度。

**页面副标题：**同一处机位，不同日子的光

## 内容结构（由上至下）

1. **比较对象** — `form`。
   - 可见元素：日期 A、日期 B
   - UI 演示值（不是设备数据）：2026-11-20 / 2026-12-20
   - 对应 ArkUI：FormField → TextInput / DatePicker / Menu
2. **比较读数** — `metrics`。
   - 可见元素：A 日暮光、B 日暮光、高度差、方位差
   - UI 演示值（不是设备数据）：示例 A / 示例 B / 依计算结果 / 依计算结果
   - 对应 ArkUI：MetricCard → Grid + Text + status
3. **太阳高度差异** — `chart`。
   - 对应 ArkUI：DataChart → Canvas（业务数据驱动）
4. **比较总结** — `list`。
   - 可见元素：日落方向移动、暮间时段长度变化、临界日期说明
   - 对应 ArkUI：ListRow → List / LazyForEach

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#FFBC6B`、辅助色 `#73D9D5`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
