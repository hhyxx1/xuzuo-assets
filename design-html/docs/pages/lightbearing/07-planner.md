# 逐光 LightBearing · 拍摄计划

> **页面 07 / 12** · `lightbearing/planner` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

创建、编辑和维护拍摄计划，带时间、机位、提醒和清单。

**页面副标题：**让好时刻成为可靠计划

## 内容结构（由上至下）

1. **计划基本信息** — `form`。
   - 可见元素：计划名称、开始时间、结束时间、地点
   - UI 演示值（不是设备数据）：滨江夕照 / 2026-11-20 16:00 / 2026-11-20 18:00 / 徐汇滨江
   - 对应 ArkUI：FormField → TextInput / DatePicker / Menu
2. **拍摄流程** — `timeline`。
   - 可见元素：到达机位、构图准备、黄金时段、蓝调收尾
   - 对应 ArkUI：TimeAxis → Scroll + Canvas + event markers
3. **拍摄准备** — `checklist`。
   - 可见元素：相机与镜头、三脚架、存储卡、天气再确认
   - 对应 ArkUI：ChecklistRow → Checkbox / persisted state
4. **关联推荐** — `list`。
   - 可见元素：黄金时段、蓝调时段、摄影提醒
   - UI 演示值（不是设备数据）：示例 16:37 / 示例 17:29 / 可设置
   - 对应 ArkUI：ListRow → List / LazyForEach

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#FFBC6B`、辅助色 `#73D9D5`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
