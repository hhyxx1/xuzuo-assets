# 逐光 LightBearing · 设置

> **页面 10 / 12** · `lightbearing/settings` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

统一管理单位、外观、提醒及离线数据策略。

**页面副标题：**精度、单位与个人偏好

## 内容结构（由上至下）

1. **显示偏好** — `settings`。
   - 可见元素：主题模式、距离单位、角度格式、时间制
   - UI 演示值（不是设备数据）：跟随系统 / 米 / 公里 / 度 / 24 小时
   - 对应 ArkUI：SettingRow → ListItem / Toggle
2. **定位与权限** — `settings`。
   - 可见元素：定位授权、数据导出、拍摄提醒、关于逐光
   - UI 演示值（不是设备数据）：仅使用时 / 手动导出 / 关闭 / 版本与协议
   - 对应 ArkUI：SettingRow → ListItem / Toggle
3. **重要声明** — `list`。
   - 可见元素：日轨计算来自实际天文内核、天气与地图需第三方服务、本 HTML 为设计预览
   - 对应 ArkUI：ListRow → List / LazyForEach

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#FFBC6B`、辅助色 `#73D9D5`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
