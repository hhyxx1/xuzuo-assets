# 逐光 LightBearing · 光线日历

> **页面 08 / 12** · `lightbearing/calendar` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

用日历格展示日期状态、日光窗口与已保存计划；极昼/极夜等异常需明确标注。

**页面副标题：**一个月的好光线，一眼看见

## 内容结构（由上至下）

1. **2026 年 11 月** — `calendar`。
   - 可见元素：月视图、光线筛选
   - 对应 ArkUI：DateGrid → Grid + calendar model
2. **本月摘要** — `metrics`。
   - 可见元素：黄金日、蓝调日、计划数、异常日期
   - UI 演示值（不是设备数据）：12 / 9 / 3 / 按位置变化
   - 对应 ArkUI：MetricCard → Grid + Text + status
3. **选中日期 · 11 月 20 日** — `list`。
   - 可见元素：晨间黄金、暮间黄金、关联计划
   - UI 演示值（不是设备数据）：根据机位计算 / 根据机位计算 / 滨江夕照
   - 对应 ArkUI：ListRow → List / LazyForEach
4. **月度时段趋势** — `chart`。
   - 对应 ArkUI：DataChart → Canvas（业务数据驱动）

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#FFBC6B`、辅助色 `#73D9D5`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
