# 逐光 LightBearing · 地图方位

> **页面 06 / 12** · `lightbearing/map` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

机位点、拍摄方向扇区与太阳轨迹分层显示。

**页面副标题：**在地图上看光线落点

## 内容结构（由上至下）

1. **拍摄地图和光线方向** — `map`。
   - 对应 ArkUI：MapSlot → Map Kit adapter（条件能力）
2. **地图模式** — `tabs`。
   - 可见元素：地形、道路、简化
   - 对应 ArkUI：SegmentedTabs → Tabs / custom component
3. **当前机位** — `metrics`。
   - 可见元素：经度、纬度、朝向、目标距离
   - UI 演示值（不是设备数据）：121.4399°E / 31.1804°N / 238° / —
   - 对应 ArkUI：MetricCard → Grid + Text + status
4. **地图图层** — `list`。
   - 可见元素：方向扇区、机位标记、地形高程
   - UI 演示值（不是设备数据）：可切换 / 可切换 / 条件支持
   - 对应 ArkUI：ListRow → List / LazyForEach

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#FFBC6B`、辅助色 `#73D9D5`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
