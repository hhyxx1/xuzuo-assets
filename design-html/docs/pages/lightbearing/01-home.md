# 逐光 LightBearing · 今日光线

> **页面 01 / 12** · `lightbearing/home` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

以当前机位和选定日期呈现黄金/蓝调时段、实时太阳参数与主要工具入口。

**页面副标题：**所见之光，提前抵达

## 内容结构（由上至下）

1. **逐光 · 今日观测** — `hero`。
   - 辅助说明：SHANGHAI · GOLDEN HOUR
   - 可见元素：下一段黄金时刻、晚间 16:37 — 17:29、摄影计划示例 · 非实时数据
   - 对应 ArkUI：HeroBanner → Stack + Image + Gradient + Button
2. **日照概览** — `metrics`。
   - 可见元素：日出、日落、方位角、高度角
   - UI 演示值（不是设备数据）：06:50 / 17:29 / 238.6° / 12.4°
   - 对应 ArkUI：MetricCard → Grid + Text + status
3. **今日太阳高度曲线** — `chart`。
   - 辅助说明：选中曲线点，可查看方位/高度示例
   - 可见元素：06:00、09:00、12:00、15:00、18:00
   - 对应 ArkUI：DataChart → Canvas（业务数据驱动）
4. **光线时段** — `timeline`。
   - 可见元素：06:24 蓝调、06:50 日出、07:37 晨黄金结束、16:37 暮黄金开始、17:29 日落
   - 对应 ArkUI：TimeAxis → Scroll + Canvas + event markers
5. **快捷工具** — `grid`。
   - 可见元素：太阳轨迹、反向寻光、机位、拍摄计划
   - 对应 ArkUI：ActionGrid → Grid / GridItem

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#FFBC6B`、辅助色 `#73D9D5`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
