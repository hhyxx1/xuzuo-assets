# 逐光 LightBearing · 机位库

> **页面 04 / 12** · `lightbearing/locations` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

搜索、筛选、收藏、排序并维护拍摄位置。

**页面副标题：**所有灵感，都有坐标

## 内容结构（由上至下）

1. **搜索机位** — `form`。
   - 可见元素：机位名称 / 坐标
   - UI 演示值（不是设备数据）：徐汇滨江
   - 对应 ArkUI：FormField → TextInput / DatePicker / Menu
2. **筛选机位** — `tabs`。
   - 可见元素：全部、收藏、最近
   - 对应 ArkUI：SegmentedTabs → Tabs / custom component
3. **机位分布预览** — `map`。
   - 对应 ArkUI：MapSlot → Map Kit adapter（条件能力）
4. **保存的机位** — `list`。
   - 辅助说明：点击进入机位详情
   - 可见元素：徐汇滨江 · 日落江景、余山 · 城市远眺、外滩 · 城市建筑群
   - UI 演示值（不是设备数据）：上海 · 收藏 / 上海 · 自然 / 上海 · 建筑
   - 对应 ArkUI：ListRow → List / LazyForEach

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#FFBC6B`、辅助色 `#73D9D5`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
