## 页面目标

项目创建、最近编辑、素材与模板入口。

**页面副标题：**从这里开始你的下一部动画

## 内容结构（由上至下）

1. **让每一帧都有生命** — `hero`。
   - 辅助说明：FRAME BY FRAME
   - 可见元素：逐帧拍摄 · 时间轴编辑 · 本地导出
   - 对应 ArkUI：HeroBanner → Stack + Image + Gradient + Button
2. **创作快捷入口** — `grid`。
   - 可见元素：新建动画、拍摄工作台、项目模板、素材库
   - 对应 ArkUI：ActionGrid → Grid / GridItem
3. **最近项目** — `list`。
   - 可见元素：纸偶冒险 · 128 帧、桌面小剧场 · 72 帧、积木城市 · 204 帧
   - UI 演示值（不是设备数据）：12 fps · 草稿 / 24 fps · 编辑中 / 12 fps · 完成
   - 对应 ArkUI：ListRow → List / LazyForEach

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#FF9471`、辅助色 `#75DDC4`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
