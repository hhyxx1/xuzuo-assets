# 帧间 FrameMori · 配音与音乐

> **页面 05 / 10** · `framemori/audio` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

导入音频、设置入点、预览和音量调节。

**页面副标题：**为画面配上节奏

## 内容结构（由上至下）

1. **音轨预览** — `waveform`。
   - 对应 ArkUI：WaveformView → Canvas + AudioPlayer
2. **音轨** — `list`。
   - 可见元素：背景音乐、拟音片段、旁白
   - UI 演示值（不是设备数据）：00:00–00:11 / 00:04–00:07 / 未添加
   - 对应 ArkUI：ListRow → List / LazyForEach
3. **轨道参数** — `form`。
   - 可见元素：音量（%）、开始时刻（秒）
   - UI 演示值（不是设备数据）：78 / 0
   - 对应 ArkUI：FormField → TextInput / DatePicker / Menu
4. **音频操作** — `grid`。
   - 可见元素：导入、静音、分割、删除
   - 对应 ArkUI：ActionGrid → Grid / GridItem

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#FF9471`、辅助色 `#75DDC4`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
