# 帧间 FrameMori · 设置与素材

> **页面 10 / 10** · `framemori/settings` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

项目自动保存、导出路径、界面和权限。

**页面副标题：**可靠保存每一帧

## 内容结构（由上至下）

1. **拍摄与项目** — `settings`。
   - 可见元素：自动保存、默认帧率、相机权限、本地素材存储
   - UI 演示值（不是设备数据）：开启 / 12 fps / 使用时 / 应用私有空间
   - 对应 ArkUI：SettingRow → ListItem / Toggle
2. **输出与外观** — `settings`。
   - 可见元素：默认视频尺寸、默认格式、主题、语言
   - UI 演示值（不是设备数据）：1080p / MP4（如支持） / 深色 / 简体中文
   - 对应 ArkUI：SettingRow → ListItem / Toggle
3. **存储管理** — `list`。
   - 可见元素：检查项目完整性、备份项目、清理临时文件
   - 对应 ArkUI：ListRow → List / LazyForEach

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#FF9471`、辅助色 `#75DDC4`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
