# 帧间 FrameMori · 动画导出

> **页面 08 / 10** · `framemori/export` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

独立的格式、尺寸、帧率选择与导出进度。

**页面副标题：**带走真正可播放的作品

## 内容结构（由上至下）

1. **导出格式** — `export`。
   - 可见元素：MP4 H.264、PNG 序列、GIF
   - UI 演示值（不是设备数据）：视频（需设备支持） / 帧序列 / 动图（需验证）
   - 对应 ArkUI：ExportOptionCard → GridItem + media task
2. **导出配置** — `form`。
   - 可见元素：宽度、高度、帧率、质量
   - UI 演示值（不是设备数据）：1920 / 1080 / 12 / 高
   - 对应 ArkUI：FormField → TextInput / DatePicker / Menu
3. **任务预览** — `progress`。
   - 可见元素：准备帧、编码、保存
   - UI 演示值（不是设备数据）：33
   - 对应 ArkUI：TaskProgress → Progress / event state
4. **验收条件** — `list`。
   - 可见元素：外部播放器能播放、视频时长与帧数相符、失败可以重试
   - 对应 ArkUI：ListRow → List / LazyForEach

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#FF9471`、辅助色 `#75DDC4`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
