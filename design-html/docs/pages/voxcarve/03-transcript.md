# 声剪 VoxCarve · 文字稿

> **页面 03 / 10** · `voxcarve/transcript` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

时间戳、说话人、文本选择、播放联动与版本记录。

**页面副标题：**在音频时间里直接编辑文字

## 内容结构（由上至下）

1. **编辑模式** — `tabs`。
   - 可见元素：文字稿、说话人、备注
   - 对应 ArkUI：SegmentedTabs → Tabs / custom component
2. **带时间戳的语句** — `list`。
   - 可见元素：00:00:04 · 说话人 A：欢迎来到今天的访谈、00:00:12 · 说话人 B：我想从设计目标开始、00:00:19 · 说话人 A：先谈谈你的创作过程、00:00:28 · 说话人 B：这是一个新的尝试
   - 对应 ArkUI：ListRow → List / LazyForEach
3. **联动音轨** — `waveform`。
   - 对应 ArkUI：WaveformView → Canvas + AudioPlayer
4. **搜索当前文字稿** — `form`。
   - 可见元素：关键词
   - UI 演示值（不是设备数据）：设计目标
   - 对应 ArkUI：FormField → TextInput / DatePicker / Menu

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#AF9DFF`、辅助色 `#FDBF92`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
