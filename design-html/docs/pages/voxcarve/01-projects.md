# 声剪 VoxCarve · 项目首页

> **页面 01 / 10** · `voxcarve/projects` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

项目搜索、录音导入、草稿和最近编辑状态。

**页面副标题：**每一段声音，都有结构

## 内容结构（由上至下）

1. **声音从这里开始** — `hero`。
   - 辅助说明：VOICE STUDIO
   - 可见元素：导入音频与视频、转写为可编辑的文字
   - 对应 ArkUI：HeroBanner → Stack + Image + Gradient + Button
2. **最近项目** — `list`。
   - 可见元素：产品访谈、团队周会、课程录音、播客第 3 期
   - UI 演示值（不是设备数据）：转写待复核 / 字幕已编辑 / 未处理 / 剪辑中
   - 对应 ArkUI：ListRow → List / LazyForEach
3. **开始工作** — `grid`。
   - 可见元素：导入文件、新建录音、文字稿、剪辑台
   - 对应 ArkUI：ActionGrid → Grid / GridItem

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#AF9DFF`、辅助色 `#FDBF92`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
