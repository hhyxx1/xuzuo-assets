# 声剪 VoxCarve · 字幕编辑

> **页面 06 / 10** · `voxcarve/captions` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

字幕分段、阅读速度、样式与导出前检查。

**页面副标题：**字幕与声音保持一致

## 内容结构（由上至下）

1. **字幕类型** — `tabs`。
   - 可见元素：逐句、双语、样式
   - 对应 ArkUI：SegmentedTabs → Tabs / custom component
2. **字幕段落** — `list`。
   - 可见元素：00:00–00:04 欢迎来到今天的访谈、00:04–00:09 让我们从问题开始、00:09–00:15 谢谢你的邀请
   - 对应 ArkUI：ListRow → List / LazyForEach
3. **字幕样式** — `form`。
   - 可见元素：单行最大字数、行数、时间偏移（ms）
   - UI 演示值（不是设备数据）：16 / 2 / 0
   - 对应 ArkUI：FormField → TextInput / DatePicker / Menu
4. **字幕操作** — `grid`。
   - 可见元素：合并、拆分、上一条、下一条
   - 对应 ArkUI：ActionGrid → Grid / GridItem

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#AF9DFF`、辅助色 `#FDBF92`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
