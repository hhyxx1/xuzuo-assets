# 声剪 VoxCarve · 设置

> **页面 10 / 10** · `voxcarve/settings` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

语言与 ASR 服务、自动保存、播放和存储。

**页面副标题：**尊重声音，也尊重隐私

## 内容结构（由上至下）

1. **音频偏好** — `settings`。
   - 可见元素：语言、转写提供方、自动保存、默认播放速度
   - UI 演示值（不是设备数据）：简体中文 / 按实际可用性 / 30 秒 / 1.0×
   - 对应 ArkUI：SettingRow → ListItem / Toggle
2. **隐私与导出** — `settings`。
   - 可见元素：默认离线优先、数据清理、导出字幕编码、主题
   - UI 演示值（不是设备数据）：是 / 手动 / UTF-8 / 深色
   - 对应 ArkUI：SettingRow → ListItem / Toggle
3. **能力说明** — `list`。
   - 可见元素：时间戳精度可能依服务而异、不承诺云转写一定可用、任何媒体上传必须征求授权
   - 对应 ArkUI：ListRow → List / LazyForEach

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#AF9DFF`、辅助色 `#FDBF92`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
