# 声剪 VoxCarve · 导出

> **页面 08 / 10** · `voxcarve/export` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

媒体与字幕独立导出，显示格式、编码和耗时。

**页面副标题：**把编辑成果交给真实播放器

## 内容结构（由上至下）

1. **可选交付** — `export`。
   - 可见元素：WAV、MP3、SRT、VTT
   - UI 演示值（不是设备数据）：无损音频 / 有损编码（验证） / 通用字幕 / WebVTT
   - 对应 ArkUI：ExportOptionCard → GridItem + media task
2. **导出选项** — `settings`。
   - 可见元素：字幕编码、保存位置、覆盖冲突、项目备份
   - UI 演示值（不是设备数据）：UTF-8 / 用户选定 / 确认再覆盖 / 推荐
   - 对应 ArkUI：SettingRow → ListItem / Toggle
3. **导出任务** — `progress`。
   - 可见元素：媒体准备、编码、写入
   - UI 演示值（不是设备数据）：0
   - 对应 ArkUI：TaskProgress → Progress / event state

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#AF9DFF`、辅助色 `#FDBF92`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
