## 页面目标

**页面副标题：**每一次剪辑都可追溯

## 内容结构（由上至下）

1. **历史版本** — `list`。
   - 可见元素：v5 · 修正字幕、v4 · 静音片段复核、v3 · 主动剪辑、v2 · 导入与转写
   - UI 演示值（不是设备数据）：今天 16:20 / 今天 15:42 / 昨天 21:00 / 昨天 20:10
   - 对应 ArkUI：ListRow → List / LazyForEach
2. **版本概览** — `metrics`。
   - 可见元素：版本数、撤销步骤、素材数、备份状态
   - UI 演示值（不是设备数据）：5 / 12 / 3 / 本地
   - 对应 ArkUI：MetricCard → Grid + Text + status
3. **历史策略** — `checklist`。
   - 可见元素：保留原媒体、版本可恢复、变更有时间范围
   - 对应 ArkUI：ChecklistRow → Checkbox / persisted state

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#AF9DFF`、辅助色 `#FDBF92`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
