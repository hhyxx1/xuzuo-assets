# 声剪 VoxCarve · 停顿复核

> **页面 05 / 10** · `voxcarve/silence` · HTML/TypeScript UI v0.1 · DRAFT_FOR_REVIEW

## 页面目标

静音片段检测与人工确认；不可一次性不可逆覆盖。

**页面副标题：**剪掉停顿之前，先让你听见

## 内容结构（由上至下）

1. **停顿候选区域** — `waveform`。
   - 对应 ArkUI：WaveformView → Canvas + AudioPlayer
2. **检测阈值** — `form`。
   - 可见元素：最短停顿（秒）、前后保留（秒）
   - UI 演示值（不是设备数据）：0.6 / 0.3
   - 对应 ArkUI：FormField → TextInput / DatePicker / Menu
3. **建议删除片段** — `checklist`。
   - 可见元素：00:12.3–00:13.1、01:48.0–01:49.4、03:03.2–03:04.3
   - 对应 ArkUI：ChecklistRow → Checkbox / persisted state
4. **变更预估** — `metrics`。
   - 可见元素：候选数量、预计缩短、操作模式、保存方式
   - UI 演示值（不是设备数据）：3 / 3.5 秒 / 人工确认 / 非破坏性
   - 对应 ArkUI：MetricCard → Grid + Text + status

## 页面状态与交互

- Normal：展示本页完整任务链
- Empty：显示原因和唯一明确的下一步
- Loading：显示真实可取消的任务状态
- Error：可恢复操作与明确错误说明
- 顶部上一页/下一页用于设计评审；产品正式导航须回到真实信息架构。
- 本页的图表/地图/摄影/媒体数据如未接业务后端，一律展示“演示”而非真实测量。

## 复用规范

- 颜色：共用深色主题底色 `#0B1622`、面板 `#152836`；本 App 专属主色 `#AF9DFF`、辅助色 `#FDBF92`。
- 间距：4vp 基准；操作热区目标 48vp；导航和状态组件从单一设计系统调用。
- 不复制新的按钮、卡片、弹窗代码。各页面只提供 typed data 与必要的专用业务组件。
